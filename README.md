# 巡甲卫士（ShieldPatrol）— 安卓本地杀毒软件

参考游龙等安卓安全软件的形态，本地规则引擎驱动的恶意软件检测与拦截工具。
最低支持 Android 8.0（API 26），targetSdk 34。

## 功能

1. **应用扫描**：遍历已安装应用，采集权限、导出组件、Dex 特征串、APK/签名哈希、动态加载、调试标志、未知来源安装等特征，按规则库打分：
   - `score ≥ 70` → 恶意；`40–69` → 可疑；`< 40` → 安全
2. **恶意类别区分**：木马(TROJAN)、勒索(RANSOMWARE)、广告劫持(ADWARE)、隐私窃取(PRIVACY_STEALER)、挖矿(MINER)、后门(BACKDOOR)、通用(GENERIC)，内置规则覆盖各家族典型行为组合
3. **本地恶意库**：APK 完整文件哈希 + 签名哈希两级黑名单，命中直接判恶意（100 分），支持文本格式导入/导出
4. **实时防护**：
   - 安装监听：新装/覆盖安装应用立即自动检测并通知
   - 开机自启后台全量扫描
5. **黑名单 / 白名单**：
   - 白名单：应用直接豁免检测（判安全）
   - 黑名单：直接判恶意并标记拦截，详情页处置
   - 支持查看、手动增删、持久化导入导出
6. **Shizuku 提权处置**（核心阻拦能力）：
   - 已授权：`am force-stop` 强制停止、`pm disable-user` 禁用、`pm uninstall -k --user 0` 卸载恶意应用，全部免弹窗静默执行
   - 未授权/未装 Shizuku：自动降级为通知告警 + 跳转系统设置页手动处置，扫描检测功能不受任何影响
7. **规则可扩展**：自定义规则文本格式 `ID;类别;权重;条件`，条件支持 permAll/permAny/dexAny/compAny/flag/maxTargetSdk，应用内导入导出

## 安装使用

1. 手机安装 APK
2. （可选但推荐）安装并启动 Shizuku（需开发者选项无线调试或 root），在本应用点"申请 Shizuku 授权"
3. 授予通知权限；首次使用点"立即扫描"
4. 扫描后进任意应用详情，可对恶意项执行强停/禁用/卸载，或加入黑/白名单
5. 恶意库/规则库页面可导入你自己的哈希黑名单文本（每行 `哈希;APK或SIG;类别;名称`）

## 能力边界（诚实声明）

- 本应用使用**自建本地规则库**，不含商业厂商病毒特征库；对已知样本哈希与行为特征有效，对未知变种依赖行为规则命中。规则与哈希库均可自行扩充导入。
- 未授权 Shizuku/root 时，Android 系统限制第三方应用无法直接杀进程或静默卸载，本应用的"阻拦"降级为告警+引导，这是系统安全模型限制，所有同类非 root 杀毒应用相同。
- Android 12+ 对后台启动应用有更严格限制，运行时阻拦以"检测结果通知 + Shizuku 处置"为主。

## 开发与测试

- `engine/`：纯 JVM Kotlin 检测引擎模块，JUnit4 单元测试 24 例（TDD 先行编写）：
  ```
  C:\Gradle\gradle-8.9\bin\gradle.bat :engine:test
  ```
- `app/`：Android 层（UI、前台扫描服务、安装监听、Shizuku、采集器）
- 构建 APK：
  ```
  C:\Gradle\gradle-8.9\bin\gradle.bat :app:assembleDebug
  ```
  产物在 `app/build/outputs/apk/debug/app-debug.apk`（debug 签名，可直接安装）
